#
# requirements.txt 는 필요한 패키지와 하한만 적는다. 이 파일은 설치 버전을 고정한다.
# Dockerfile 이 `pip install -c constraints.txt -r requirements.txt` 로 함께 읽으므로, 이미지를 언제 다시
# 만들어도 같은 버전이 설치된다. 고정이 없으면 다시 만들 때마다 최신 버전이 들어와 동작이 달라질 수 있다.

# 올리는 방법: 해당 줄을 고치고 이미지를 만든 뒤 테스트와 서로 다른 경로 5건 이상의 경로 탐색을 확인하고 커밋한다.
